# 日常使用

车机打开 CarLife 后，未投屏时会显示 CarLink 菜单。选择 CarPlay 或 HiCar，再选择「连接设备」。在手机上确认连接。添加 HiCar 设备时，在手机上输入菜单显示的固定 PIN。

- **自动连接**：默认可按上次使用的协议启动，也可在菜单中指定 CarPlay 或 HiCar。已登记设备可按当前连接策略重连。手动断开会暂停自动连接，选择「连接设备」恢复。
- **切换协议**：打开菜单并选择另一协议。盒子停止旧接收端再启动新接收端，CarLife USB 服务由管理器独立维护。
- **打开菜单**：点击 CarPlay 的「CarLink菜单」或 HiCar 的返回车机图标。兼容的实体返回键可快速按三次打开菜单。点首行「返回投屏」或按返回键恢复画面。查看菜单时保留投屏会话和音频。
- **音量**：在「声音」中以 5% 为步长调整，范围 0–150%，默认 100%。调节作用于下行播放，不改变麦克风增益。超过 100% 可能出现削波。
- **操作提示音**：默认开启，可在「声音」中关闭。有效点击或焦点移动播放短提示，通话期间停用。触控板和实体按键可用性取决于车机发送的事件。

管理接口可查询当前协议和设备状态：

```sh
carlink manager ctl /run/carlink-manager/control.sock '{"op":"status"}'
carlink manager ctl /run/carlink-manager/control.sock '{"op":"devices"}'
```
