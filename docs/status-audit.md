# 完成情况核对（2026-10-27）

初次核对基线为 `4e4fd06`，功能基线为 `a47a9f0`。现已补入双向通话代码、更新台架运行版本，并将自动化回归与真实通话结果分别记录在 [validation.md](validation.md)。

## R2 与 R3 的实际含义

R2 的 **HiCar Rust 迁移**已完成：BlueZ、热点、认证、DMSDP、HiSight、视频接收、AAC 解码、输入和生命周期均由 Rust 后端管理。Python HiCar 探索代码保留作协议参考和对照测试。

R3 的 **统一连接管理**已实现并通过既有台架回归：常驻 CarLife、单无线后端、设备记录、配对入口、固定 PIN 页面、协议切换、断线回菜单、开机恢复和三连返回入口。

两项阶段结果的范围是基础投屏链路与连接管理。下面分别列出代码缺口和外部验收，避免将尚未实现的语音功能写成仅待实车测试。
