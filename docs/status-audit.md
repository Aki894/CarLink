## 保留的能力边界和优化项

- **HiCar 导航/助手路由**：按 SSRC 独立解码，但非通话流最终混入 MEDIA；还没有独立 TTS/VOICE 路由和本地 ducking。见 `app/src/hicar/live.rs:230,277–290,398`。先取得 Lexus 声道结果，再决定映射和压低策略，避免重复压低手机已经处理的音乐。
- **语音和电话硬键**：当前提供方向、确认、返回、主页和媒体键；语音助手与接听/挂断主要依赖投屏界面，未完整实现原车专用键映射。见 `app/src/input.rs:57–64`、`app/src/hicar/live.rs:311`。需先确认原车实际发送的消息。
- **HiCar 音画同步/抖动恢复**：下行主要按到达时间建立播放时间线，RTP 到本地时钟映射尚未接入，重排缺少时间到期排空。见 `app/src/hicar/live.rs:254,283`、`app/src/hicar/media.rs:82`。作为长时间同步和弱无线环境优化跟踪。
- **运行包体积**：热路径已迁移 Rust，但 `scripts/build-carplay.sh:80–84` 仍打包旧 HiCar Python 实验和依赖；可在正式运行包与研究/诊断包分离后精简。
- **HiCar 入口外观**：功能入口已经完成，目前保留系统名称/图标；独立自定义标签/图标仍是可选外观项。
