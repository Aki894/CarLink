# 故障排查

| 现象 | 优先检查 |
| --- | --- |
| 车机未识别盒子 | 车机是否支持有线 CarLife、USB 口是否支持数据、线材是否传输数据、盒子的端口是否为 USB 设备口。 |
| 识别后连接失败 | 记录从插入到失败的时间，检查系统日志中的 USB 枚举、AOA 和 CarLife 握手。 |
| 搜不到无线设备 | 检查菜单当前协议、配对窗口、手机蓝牙和 Wi-Fi，以及是否已有另一台手机连接。 |
| CarPlay 无法启动 | 检查本地 MFi 文件和权限，以及管理器和接收端是否来自同一构建。 |
| HiCar 首次配对失败 | 在菜单进入连接设备流程，核对当前显示的 PIN。若手动投屏成功而开启自动连接失败，记录手机提示和蓝牙授权错误。 |
| 音乐、导航或通话无声 | 分别验证三种声音以及双向通话。车机对媒体和导航声道的支持可能不同。 |
| 触控板或按键无效 | 分别检查焦点移动、确认和返回。兼容性诊断应记录车机是否向 CarLink 发送对应事件。 |

```sh
carlink doctor --json
carlink wifi-interface
systemctl status carlink
journalctl -u carlink -b --no-pager
```

反馈问题时，请附 CarLink 提交或固件版本、手机系统版本、失败步骤和相关日志片段。分享前删去蓝牙地址、配对码、密钥、凭据和其他个人信息。原始蓝牙抓包可能含密钥。
